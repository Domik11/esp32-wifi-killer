# Проверка конфиденциальных данных перед публикацией

Дата: 26.10.2026.

## Область проверки

- Подготовленные к публикации исходники ESP32 и Windows-приложения.
- README, инструкции, настройки сборки и GitHub Actions.
- Существующая история репозитория до публикации: один коммит с лицензией.
- Собранный Windows exe, включая распакованные элементы PyInstaller и PYZ.

Отчёты инструментов с деталями локальных путей в репозиторий не включаются.
Архив оригинального скетча, журналы сборки/платы, локальные настройки IDE,
виртуальное окружение и промежуточные бинарники также исключены.

## Исправлено

- Удалён локальный заголовок со старым Wi-Fi паролем и его подключение.
- Пароль вводится через GUI/Serial, хранится только в RAM для переподключения.
- Установлен WiFi.persistent(false), новые учётные данные не пишутся во flash.
- Удалены локальные пути из публикуемой конфигурации.
- Примеры статической конфигурации заменены документационными IPv4-адресами.
- Расширен .gitignore для секретов, журналов, сборок и IDE-настроек.

## Ограничения и оставшиеся свойства

Это проверка утечек известных данных и сигнатур секретов, а не гарантия
отсутствия любых уязвимостей. Проверка не включала содержимое NVS подключённой
платы, историю других локальных проектов или посторонние файлы пользователя.
Существующая Git-история не переписывалась.

Старые Wi-Fi настройки, ранее записанные другими прошивками, могут оставаться
в NVS платы. Они не экспортировались и не публиковались. Их удаление требует
отдельного решения владельца, поскольку может затронуть сохранённые данные.

Во время работы приложение показывает SSID, IP, MAC и имена локальных устройств.
Само приложение не сохраняет журнал на диск, но пользователь может раскрыть
эти данные в скриншоте или копии вывода. Пароль передаётся по USB без шифрования.
Wi-Fi драйвер и приложение держат его в оперативной памяти, что не защищает
от доступа к памяти на скомпрометированном компьютере или плате.

DNS/ICMP-запросы к yandex.ru являются частью диагностики. Режим автоматического
присвоения чужого IP ESP32 сохранён по выбору владельца проекта и описан
в README как функция для изолированного учебного стенда.
